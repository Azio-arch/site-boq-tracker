# AI-Based Small-Scale Construction Coordination System

A lightweight coordination system for a small construction project where vendors are already selected.

It monitors agreed activity timelines, planned vs actual progress, and agreed vs actual costs. An AI/ML layer flags activities with higher delay/progress/cost risk and analyses vendor/site updates for delays, commitments and cost-impact signals.

**Tech:** Python, Pandas, NumPy, Scikit-learn, Random Forest, Streamlit, Joblib.

The data is synthetic. This is a demonstrable prototype inspired by construction/project coordination workflows, not a system deployed at a former employer.
